## How this documentation is organized

- **`episodes/`** — one markdown file per episode. Each file is structured by *concept*, not by transcript timestamp, so it reads as a coherent explainer rather than a raw transcript.
- **`glossary.md`** — a single running Kannada–English glossary of all ZBNF terms introduced across episodes, deduplicated.
- Each episode file uses a consistent structure: front-matter metadata → episode summary → concept sections → key takeaways → glossary terms introduced → open questions for future episodes.
- Claims stated by hosts/guests that are opinion, folk framing, or unverified figures (not general agricultural science) are explicitly flagged **[Speaker's claim]** so downstream readers/AI systems can distinguish established practice from personal assertion.
